# Kotlin
- Linguagem multiplataforma, multiparadigma e consistente
- Compilado e executado em ambiente Java (JVM)
- Projeto Open Source

## Características
- Linguagem Oficial do Android: O Google declarou o Kotlin como a linguagem oficial para o desenvolvimento de aplicativos Android, substituindo ou complementando o Java.
- Interoperabilidade com Java: É possível usar código Java dentro do Kotlin e código Kotlin dentro do Java.
- Segurança contra valores nulos: O sistema de tipos do Kotlin foi desenhado para evitar o erro NullPointerException.
- Sintaxe Concisa: Escreve-se muito menos código para realizar a mesma tarefa que em linguagens mais antigas, como o Java.
- Multiplataforma (KMP): Permite compartilhar a lógica e regras de negócio entre diferentes sistemas operacionais (Android, iOS, Windows, macOS e Linux).

## Exemplo Java x Kotlin
``` java
// Java
class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}
```

``` kotlin
// Kotlin
fun main(args : Array<String>) {
  println("Hello, World!")
}
```
